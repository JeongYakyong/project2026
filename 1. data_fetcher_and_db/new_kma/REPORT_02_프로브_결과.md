## 2. ★발견 1 — 신 std API 의 전구 "화면고도 변수" 디코딩 버그

같은 값**이 나온다 (제주·서산·서울·적도 모두 동일 — 위치 불변 = 사용 불가).

## 5. 신구 교차검증 — 지역 모델 값은 그대로 신뢰 가능

같은 R030 모델을 구 grib(운영 제주 수집기)과 신 std 로 동시에 읽어 비교 (솔라팜, hf 12~21, 8변수):
**최대 차이 0.005** = 2byte 압축의 양자화 한계. 바람 성분까지 완전 일치(회전 없음).
→ 제주 운영 수집(구 grib)과 신 API 는 같은 데이터다. 어느 쪽을 써도 값은 같다.

## 6. 일사 물리 검증 (서산, 맑은 날 하루)

- `SWDDIR2 ÷ (SWDDNI2 × cos천정각) = 1.00` → **SWDDIR2 = 수평면 직달** 확정
- **GHI(전천일사) = SWDDIR2 + SWDDIF2** — 정오 약 1,000 W/m² (7월 맑은 날값으로 타당)
- 현행 DB 규약 그대로: `radiation(MJ/m²·h) = GHI × 0.0036` (dswrsfc 변환식과 동일)
- **ACSWDNB** = 발표 기준 누적(MJ/m²), hf=0 에서 0, 리셋 없음 → 시간 차분 = 시간당 일사 에너지.
  현행 강수 누적(rainc_acc) diff 패턴을 그대로 재사용 가능.
- 덤: 직달/산란/법선면 분리는 태양광 예측에 현행(전천일사 하나)보다 풍부한 입력.

## 7. 운량 — 지역·국지에는 없다 (대안 평가)

- 문서(PDF)에는 LCDC/MCDC/HCDC 가 있지만 **실제 파일에는 미탑재**("Variable not found").
  구 grib 의 TCOG/TCOH 는 응답은 하지만 0 고정(사실상 사망).
- 등압면 CLDFRA(레벨별) 랜덤 오버랩 결합은 물리적으로 정합 — 비 오는 제주 ≈ 1.0, 맑은 서산 = 0.0
  (같은 모델의 일사 예측과도 일치). 그러나 시각당 18콜(레벨당 1콜)이라 운영엔 부적합, EDA 용.
- **결론: 운량은 현행처럼 전구(tcld/mcld/lcld)에서 병합 유지.** 현행 구조가 이미 이렇게 돼 있어 변화 없음.

## 8. ★발견 2 — 구 pt 엔드포인트가 신모델 3종을 전부 지원

`nph-kim_nc_pt_txt2`(현행 전구 수집기의 엔드포인트)에 `group=KIMR&nwp=R030` / `group=KIML&nwp=L010` 을
주면 지역·국지도 정상 응답한다:
- 위경도 직접 입력(격자 변환 불필요), 응답 헤더의 X/Y = 우리 변환표와 일치(검증 겸용)
- **콤마 멀티변수 1콜** — 신 std 는 변수당 1콜이라 같은 일에 콜 10배 이상
- 신규 변수 전부 확인: U140/V140/U220/V220, SWDDIR2/SWDDIF2/SWDDNI2, ACSWDNB, TSKIN, PBLH, VIS, RAIN

→ **기존 수집 엔진(`_common.py` fetch_one_hf 패턴)에서 group/nwp/name 만 바꾸면 지역·국지 확장 완성.**

## 10. 추가 연구(같은 날 오후) — "임의 위경도" std API 와 frcc 전운량 대체 (nb05)

사용자가 문서 2.2.2 에서 찾아낸 **`nph-kim_nc_pt_txt2_std`(임의 위경도의 자료)** 를 검증한 결과,
**이 엔드포인트가 최종 승자다**:

| 확인 항목 | 결과 |
|---|---|
| 위경도 직접 입력 (격자 변환 불필요) | ✓ (X/Y echo = 우리 변환표와 일치) |
| 콤마 멀티변수 1콜 | ✓ |
| **등압면 data=P + level 생략 = 24레벨 프로파일 1콜** | ✓ |
| 전구 화면고도 버그(§2, xy_txt2_std 의 문제) | **없음** — 정상 디코더 |

→ 구 pt 와 같은 정상 디코더 + 신세대 인자 체계. **구 pt 폐지 리스크의 대비책이 이미 존재**함을 뜻한다.

**frcc(등압면 운량, GRIB 6032 = nc 의 CLDFRA) → 전운량 대체 검증**:
- 구 grib `varn=6032&data=P&ef=범위` 로 **여러 시각 × 24레벨을 1콜**에 받는다(96시각까지 1콜 실증,
  120시각 요청은 빈 응답 → **D+1~5 는 2콜 분할**. hf 121·122 는 R030 창 밖이라 원래 없음).
- 결합식 = max-random 오버랩(붙은 층은 최대값, 떨어진 덩어리끼리 랜덤) + 저/중/상층 분해(≥800 / 450~799 / <450 hPa).
- 물리 정합: 아침 저층운(0.61~0.86)에서 R030 자체 일사 투과율이 0.53~0.69 로 급락 — 정합.
  불일치는 전부 얇은 상층 권운이 전운량에 잡히는 경우로, **실제 관측 전운량·NE57 tcld 도 동일한 성질**
  (NE57 tcld 0.97 인데 일사 755 W/m² 사례). 층별 분해 덕에 현행보다 정보가 오히려 풍부.
- 결론: **지역·국지 1h 운량 확보 가능** — §7 의 "운량은 전구 병합만" 판정을 갱신한다(전구 병합=기본,
  frcc 결합=1h 대체·보강 옵션, 지점당 2콜).
