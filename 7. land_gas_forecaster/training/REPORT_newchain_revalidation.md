# 가스(7) 새 체인 정직 재검증 — 5·6 구조변경 영향 점검 (2026-06-21)

## 1. 왜 했나
5단계(수요)가 **PatchTST v4 + 지평별 파인튜닝**(G-24), 6단계(신재생)가 **landsolar504**(06-19)로
구조가 바뀌었다. 서빙 체인(`serve_chain_land_new.py`)은 이미 새 구조로 돌지만, 가스의 **공개 정확도
(전체 13.72%)와 후처리(낮/밤 보정·블렌딩 w(h))는 모두 옛 수요(하이브리드)·옛 6단계로 측정·적합된
값**이었다. 즉 새 체인의 실제 가스 성능이 측정된 적이 없었다. "가스 구조를 바꿔야 하나"를 답하려면
먼저 정직 재측정이 필요했다.

## 2. 방법 (배포본 그대로 검증)
- 옛 `build_horizon_backtest.py`는 옛 수요(5-A2)·옛 가스(7-A2 util)로 굳었고 이동·수정 금지 대상 →
  **건드리지 않음.**
- 대신 **현재 배포 체인 함수 `serve_chain_land_new.build_base`**(v4 수요 + landsolar504 신재생 +
  가스 v2 + 낮/밤 보정 + 기후값 블렌딩)를 그대로 import 재사용해 forecast_horizon **186 base
  (2025-12-15~2026-06-18)** 전체에서 실측(`gen_gas_kr`)과 대조. → 지금 돌아가는 그 코드를 검증.
- 누수 차단: 기상=그 base 의 실제 예보(forecast_horizon), 가스 자기회귀 시드(rec24/168·lag)는
  origin O(=base 23:00) 이하 historical 만 참조.
- 스크립트 `validate_newchain_gas.py` → `newchain_gas_backtest.parquet`(가스 평가 20,688행).

→ "겨울 과소 / 여름 과대" 갈림은 **가스 모델의 기존 문제**(2022–24 학습·절대 MW 타깃 → 2026 LNG

만든 것이 아니다.** 여름·가을 표본은 아직 얇다(여름 n=2,096·6월만, 가을 0).

## 4. 결론
- **가스 모델 구조 변경 불필요.** 5·6 구조 변경에도 (1) 서빙 정상, (2) 정확도 오히려 개선
  (13.72→12.81%), (3) 우려했던 한낮 부호 역전 없음.
- 남은 것은 5·6과 무관한 기존 과제 = 계절별 bias(겨울 과소/여름 과대). **데이터(여름·가을)가 더
  쌓인 뒤** 블렌딩 w(h)·보정표를 새 오차 프로파일로 재적합하는 것이 권장. 지금 당장의 재적합은
  표본 편향(겨울·봄 위주)으로 여름을 거꾸로 키울 위험이 있어 보류.
- (선택) 한낮 비대칭(α4)이 이제 거의 불필요 → 차후 가스 재학습 시 α 완화 검토 가능(현재 무해하므로 급하지 않음).
