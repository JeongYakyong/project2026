# 가스(7) 재검증 — 기후값 블렌딩 제거(블렌딩 OFF) 2026-06-22 (G-28)

## 한 줄
6단계가 G-27(2026-06-22)로 장지평 재훈련된 뒤 가스를 다시 정직 검증해 보니, **옛(06-15·옛
6단계 기준) 기후값 블렌딩이 새 체인에서는 D+5~15 전 계절 MAPE 를 키우고** v3 가 고쳐 놓은 겨울 밤
과소를 도로 끌어내렸다. → **블렌딩을 껐다(calib 처럼 OFF, 적합값은 보존).** 가스 모델(v3)은 그대로,
재훈련 없음.

## 왜 다시 봐야 했나 (5→6→7 순서 문제)
- 단계 점검 순서는 5→6→7 인데, 가스 v3(G-25, 06-21)·calib·블렌딩이 **6단계 재훈련(G-27,
  06-22) 이전**에 굳었다. 즉 7단계 후처리가 **옛 6단계 출력 기준**으로 맞춰져 있었다.
- 그런데 서빙 체인(`serve_chain_land_new.py`)은 6단계 모듈(`serve_solarwind_land`)을 그대로
  import 하므로 **production 가스는 이미 새 6단계(`_final` 가중치) 위에서 돌고 있었다** — 검증만
  안 된 상태.
- 가스의 후처리는 두 겹: **calib 곱셈(이미 OFF, 06-15)** + **기후값 블렌딩(살아있음, w 0→0.5)**.
  둘 다 `gas_serving_calib.json` 의 `derivation` 대로 06-15 에 옛 6단계·옛 수요로 적합된 값.

## 핵심: 모델 가중치는 6단계 변경에 무효화되지 않는다
- 가스 v3 는 **실측 신재생**(`renew_gen_total_kr / 용량`)으로 학습한다(teacher forcing). 6단계의
  *예측* 이 바뀌어도 모델이 배운 함수는 그대로다 → **재훈련 불필요.**
- 6단계 변경이 가스에 닿는 곳은 **서빙 시 입력**(`renew_util`)뿐. 6단계가 더 정확해지면 가스
  입력이 좋아져 오히려 도움이 된다.

## 증거 (est_horizon_land 189 base, 새 6단계, 실측 대조)
6단계 재훈련 백필로 production 출력에 이미 "새 6단계 → 가스" 결과가 있어, 체인 재실행 없이 직접 측정.
블렌딩 ON(현재) vs raw(블렌딩 OFF)를 **같은 예측값 위에서** 비교(상대 비교라 in-sample 무관).

| 지표 | raw(블렌딩 OFF) | 블렌딩 ON(옛) |
|---|---|---|
| 전체 MAPE | **9.69%** | 10.04% (+0.35%p 악화) |
| D+15 MAPE | 11.19% | 12.09% (+0.89%p 악화) |
| 겨울 밤 D13-15 bias | **−0.3%**(중심) | **−4.2%**(과소 재발) |
| 여름 밤 D13-15 bias | +5.6% | **+8.6%**(과대 악화) |
| 봄 낮 D13-15 bias | −3.9%(과소) | **+5.1%**(부호 뒤집힘) |

- 블렌딩은 **D+1~4 무영향(w=0)**, **D+5 부터 모든 계절·지평에서 MAPE 증가**(전체 +0.35%p,
  D+15 +0.89%p / 겨울 +0.17·봄 +0.37·여름 +0.85%p).
- 구조적으로도 해롭다: **2022–24 기후값 = 옛 원전 레짐**(원전↑·야간 가스↓)이라, 블렌딩이
  겨울 밤 가스를 도로 끌어내려 v3 가 제거했던 과소(−0.3→−4.2%)를 되살린다. v3 보고서가 적어둔
  "장지평 야간 과소 되돌릴 미세 위험"이 새 체인에서 실제로 터졌다.
- 원래 블렌딩이 도움됐던 이유(옛 6단계는 장지평 신재생이 부정확)는, **새 6단계가 '멀수록 평년
  수축'을 직접 학습**하면서 사라졌다 → 블렌딩은 이제 중복·역효과.

## 조치 (사용자 확정)
- **블렌딩 OFF.** `gas_serving_calib.json` 에 `"blend_enabled": false` 추가, `serve_land_gas._load_calib`
  가 false 면 모든 지평 w=0 으로 반환(calib OFF 패턴 그대로). **`blend_weight_by_horizon` 적합값은
  보존**(되돌리기 쉽게). calib 는 계속 OFF.
- **모델·calib 변경 없음. 재훈련 없음.** v3 가 production 최신 가스 모델.
- production 동기화: 블렌딩만 바뀌고 수요·신재생·raw 가스는 불변이므로, 전체 체인 재백필 대신
  `est_horizon_land` 직접 갱신(`est_gas_gen_land := est_gas_gen_land_raw`,
  `est_gas_sendout_ton_land := raw × 0.1521`) — 재백필과 정확히 동일. 63,554행 갱신, 전체 MAPE
  10.04→**9.69%**·bias +1.0→**+0.6%**.

## 검증
- `_load_calib` w 합계 0·calib dev 0 확인. 체인 `build_base`(최신 base) 최종 가스 == raw(최대차 0.0,
  장지평 포함).
- 갱신 후 `est_horizon_land` 최종==raw(차 0.0), 정직(in-sample) 전체 MAPE 9.69%.

## 봉인(out-of-sample) 재검증 — foldC × 2026-04~06 (새 체인 기준)
train≤2026-03 모델(`lgbm_land_gas_v3_foldC.txt`)로 학습에 안 들어간 2026-04~06(82 base)을 새 체인
(새 6단계 + 블렌딩 OFF)으로 예측·실측 대조. `validate_newchain_gas.py --model foldC --base-min
2026-04-01 --horizons 1..15` → `newchain_gas_sealed_g28.parquet`(25,031 평가행).
- **정직 헤드라인**: 전 지평 D+1~15 **13.20%**(bias +0.2%). 옛 헤드라인과 동일 조건(지평
  1,2,3,7,12만) **12.33% ≈ 옛 12.36%** → 6단계 교체+블렌딩 OFF에도 정직 정확도 동일 수준(재작업 비용 없음).
- **블렌딩 OFF ≥ ON 봉인 확인**(raw 컬럼으로 ON 반사실 복원 비교): 전체 OFF 13.20% vs ON 13.25%
  (ON +0.06%p 손해). 단기 D+1~7 거의 동률(w 작음), 장지평 ON 불리(D+8 +0.20·D+12 +0.23·**D+15
  +0.67%p**). in-sample(+0.35%p)보다 손해폭 작음 = 봉인 raw 가 거칠어 기후값 수축이 일부 상쇄(그래도
  순효과 OFF 우위·최장지평서 명확).
- **한계**: 봉인 기간이 봄·여름뿐이라 **겨울 밤 검증 불가**(G-25 한계 동일). 겨울밤 과소 되살림 근거는
  in-sample + 메커니즘(2022–24=옛 원전레짐)으로만 성립. 봉인 bias 격자(블렌딩 OFF): 여름 밤 +7~+9.6%
  (v3 여름 표본 얇음)·봄 낮 장지평 −6%(예보기상 한계) — 둘 다 블렌딩 무관한 v3/상류 특성.

## 남은 것 / 한계
- **서버 배포는 사용자 수동**: 서버의 `serve_land_gas.py`·`gas_serving_calib.json` 동기화 +
