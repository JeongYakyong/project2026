- **A. 우리가 만든 차트** — `9. design/report/**` 안 파이썬 스크립트로 그림. 데이터는 우리 DB(`input_data_land.db`)와 `second_dataset`.

- **E. 외부 공개통계 인용** — 그림 안 캡션에 출처가 이미 적혀 있음.

## 요약

- 차트류 대부분은 `9. design/report/` 안 스크립트가 원본이고, 데이터는 `input_data_land.db`(historical 테이블)와 `second_dataset` CSV/parquet에서 나옴.
- 산점도(13쪽)와 도시가스 계절성(14쪽 아래)만 각 단계 EDA 폴더(6단계 EDA 노트북, 10단계 도시가스 빌더) 산출물임.
- 데모·API 화면(4·15·16·17쪽)은 `8. streamlit`·서빙 API의 실제 실행 화면 캡처라 별도 이미지 파일이 아님.
- 개념 삽화·구조도·로드맵(7·10 3박스·11 모델표·20 로드맵)은 문서/PPT에서 직접 만든 설명용 그림이라 밑에 깔린 데이터 출처가 없음.
- 외부 통계(6쪽 두 그림)는 그림 안 캡션에 출처가 이미 적혀 있음.
